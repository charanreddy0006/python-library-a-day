# 📂 Day 90 - File Type Detector using FileType

## 📌 Overview

On Day 90 of my **Python Library A Day** challenge, I explored the **filetype** library by building a **File Type Detector**.

Unlike checking a filename extension, this project identifies a file using its binary signature (magic bytes), making detection more reliable.

---

## 🚀 Features

- Detects file type from content
- Displays file extension
- Displays MIME type
- Handles unknown file formats
- Beginner-friendly CLI application

---

## 📦 Installation

```bash
pip install filetype
```

---

## ▶️ Run

```bash
python file_detector.py
```
