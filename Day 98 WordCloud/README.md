# ☁️ Day 98 - Word Cloud Generator using WordCloud

## 📌 Overview

On Day 98 of my **Python Library A Day** challenge, I explored the **WordCloud** library by building a **Word Cloud Generator**.

This application reads text from a file, analyzes the frequency of words, and generates a visual word cloud where frequently used words appear larger than less frequent words.

Word clouds are widely used in Natural Language Processing (NLP), data visualization, and text analytics.

---

# 🎯 Project Objective

The objective of this project is to visualize text data by generating an attractive word cloud.

The application allows users to:

- Read text from a file
- Generate a word cloud
- Save the visualization as an image
- Display the generated image
