# 📊 Day 89 - Student Exam Statistics Analyzer using Pingouin

## 📌 Overview

On Day 89 of my **Python Library A Day** challenge, I explored the **Pingouin** library by building a **Student Exam Statistics Analyzer**.

This project reads student marks from a CSV file and performs basic statistical analysis such as mean, median, standard deviation, and a normality test.

---

# 🚀 Project Objective

The objective is to analyze student performance using statistical methods instead of manual calculations.
