# 🏷️ Day 83 - SEO URL Generator using Python Slugify

## 📌 Overview

On Day 83 of my **Python Library A Day** challenge, I explored the **Python Slugify** library by building an **SEO-Friendly URL Generator**.

The project converts blog titles, product names, or article headings into clean, readable, and SEO-friendly URLs.

This functionality is commonly used in content management systems (CMS), blogging platforms, e-commerce websites, and web applications.

---

# 🚀 Project Objective

The objective of this project is to automatically generate URL slugs from user-provided titles.

The application allows users to:

- Enter a blog or product title
- Convert it into an SEO-friendly slug
- Display the complete URL
- Generate multiple URLs interactively
