# 🔤 Day 93 - Text Similarity Checker using TextDistance

## 📌 Overview

On Day 93 of my **Python Library A Day** challenge, I explored the **TextDistance** library by building a **Text Similarity Checker**.

This project compares two pieces of text and calculates how similar they are using the **Cosine Similarity** algorithm. It displays both the similarity score and percentage, making it useful for text comparison tasks.

---

## 🎯 Project Objective

The objective of this project is to understand how text similarity algorithms work and how they can be used in Python applications.

The application allows users to:

- Compare two text strings
- Calculate similarity score
- Display similarity percentage
- Classify the similarity level
