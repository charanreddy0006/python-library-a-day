# 📊 Day 84 - Student Report Generator using Tabulate

## 📌 Overview

On Day 84 of my **Python Library A Day** challenge, I explored the **Tabulate** library by building a **Student Report Generator**.

The application allows users to add student records, calculate grades based on marks, and display the data in a clean, formatted table in the terminal.

This project demonstrates how Tabulate can improve the readability of command-line applications by presenting structured data in an attractive tabular format.

---

# 🚀 Project Objective

The objective of this project is to:

- Store student information
- Calculate grades automatically
- Display records in a professional table
- Improve CLI output formatting
