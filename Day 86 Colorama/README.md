# 🎨 Day 86 - Terminal Task Manager using Colorama

## 📌 Overview

On Day 86 of my **Python Library A Day** challenge, I explored the **Colorama** library by building a **Terminal Task Manager**.

The application allows users to create tasks, mark them as completed, and view them with colorful terminal output. Using colors improves readability and enhances the user experience in command-line applications.

---

# 🚀 Project Objective

The goal of this project is to learn how to use Colorama to create visually appealing terminal applications.

The application allows users to:

- Add new tasks
- View all tasks
- Mark tasks as completed
- Display colored status messages
