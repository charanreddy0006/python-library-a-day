# 🌍 Day 80 - PyCountry

## 📌 Overview

Today I explored the **PyCountry** library by building a **Country Lookup Tool**.

This project allows users to enter a country name and retrieve standardized country information based on ISO standards.

---

## 🚀 Features

- Search country by name
- Display official country name
- Display Alpha-2 country code
- Display Alpha-3 country code
- Display numeric country code
- Interactive command-line interface

---

## 📦 Installation

```bash
pip install pycountry
```

---

## ▶️ Run

```bash
python country_lookup.py
```
