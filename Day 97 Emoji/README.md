# 😀 Day 97 - Emoji Text Converter using Emoji

## 📌 Overview

On Day 97 of my **Python Library A Day** challenge, I explored the **Emoji** library by building an **Emoji Text Converter**.

This application converts emoji aliases into real emojis and also converts emojis back into their text aliases. It demonstrates how emoji processing can be integrated into chat applications, messaging systems, and automation tools.

---

# 🎯 Project Objective

The objective of this project is to learn how Python can process emojis for text-based applications.

The application allows users to:

- Convert emoji aliases to emojis
- Convert emojis back into aliases
- Understand emoji encoding
- Build simple messaging utilities

# 🚀 Why Emoji?

The Emoji library provides a simple interface for working with emojis in Python. It supports thousands of Unicode emojis and makes text processing much easier for modern applications.
