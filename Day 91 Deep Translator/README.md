# 🌍 Day 91 - Multi-Language Text Translator using Deep Translator

## 📌 Overview

On Day 91 of my **Python Library A Day** challenge, I explored the **Deep Translator** library by building a **Multi-Language Text Translator**.

This application translates text from one language to another using Google Translator through the `deep-translator` library. It automatically detects the source language and translates the input into the selected target language.

---

## 🎯 Project Objective

The objective of this project is to understand how translation APIs work and how Python can be used to build simple multilingual applications.

The application allows users to:

- Enter any text
- Automatically detect the source language
- Translate the text into different languages
- Display the translated result instantly
