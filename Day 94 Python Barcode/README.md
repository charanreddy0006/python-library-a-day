# 🏷️ Day 94 - Product Barcode Generator using Python-Barcode

## 📌 Overview

On Day 94 of my **Python Library A Day** challenge, I explored the **Python-Barcode** library by building a **Product Barcode Generator**.

This application generates a barcode image from a product ID entered by the user. The generated barcode can be used for inventory systems, retail products, warehouse management, and logistics.

---

## 🎯 Project Objective

The objective of this project is to learn how barcode generation works and how it can be integrated into Python applications.

The application allows users to:

- Generate Code128 barcodes
- Save the barcode as a PNG image
- Create unique product identifiers
- Automate barcode creation
