# 📋 Day 96 - Clipboard Manager using Pyperclip

## 📌 Overview

On Day 96 of my **Python Library A Day** challenge, I explored the **Pyperclip** library by building a **Clipboard Manager**.

This application allows users to interact with the system clipboard directly from Python. Users can copy text, view the current clipboard contents, and clear the clipboard using a simple command-line interface.

---

## 🎯 Project Objective

The objective of this project is to learn how Python applications can interact with the operating system clipboard for automation and productivity tasks.

The application allows users to:

- Copy text to the clipboard
- View clipboard contents
- Clear clipboard contents
- Perform clipboard operations through a simple menu
