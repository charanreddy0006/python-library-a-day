# ✅ Day 87 - URL, Email & IP Validator using Validators

## 📌 Overview

This project demonstrates the **Validators** library by building a simple validation tool for URLs, email addresses, and IPv4 addresses.

Instead of writing complex regular expressions, the Validators library provides an easy and reliable way to validate common types of user input.

---

# 🚀 Project Objective

The application allows users to:

- Validate website URLs
- Validate email addresses
- Validate IPv4 addresses
- Learn input validation with a simple CLI application
