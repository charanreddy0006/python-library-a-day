# 🚫 Day 81 - Better Profanity

## 📌 Overview

On Day 81 of my **Python Library A Day** challenge, I explored the **Better Profanity** library by building a **Profanity Checker**.

This project checks whether a user's message contains offensive words and automatically censors them.

Content moderation is an important feature in modern applications, and this library makes it easy to implement.

---

## 🚀 Features

- Detect offensive words
- Automatically censor inappropriate language
- Interactive command-line interface
- Supports multiple checks
- Simple and beginner-friendly

---

## 📦 Installation

```bash
pip install better-profanity
```

---

## ▶️ Run

```bash
python profanity_checker.py
```
